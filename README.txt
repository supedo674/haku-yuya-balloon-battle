ハクvsゆや バルーンバトル Ver5.0
====================================

【Ver4.9 画面更新】
足場に立つハクとゆやの画像を使ったゲームトップ画面を追加しました。
トップ画面からCPU対戦、1台で2人対戦、オンライン部屋を選択できます。
対戦画面のタイトルを「ハクvsゆや バルーンバトル」の1行表示に変更しました。
行動ボタンをステージより上へ移動し、選択後に画面を見るための上スクロールを不要にしました。
オンライン部屋は接続完了後にステージ下へ自動移動し、操作画面を上側へ戻します。

【遊び方】
CPU対戦ではプレイヤーがハク、CPUがゆやを担当します。
「1台で2人対戦」を選ぶと、従来の交代制対戦も遊べます。
両者の行動決定後に結果を同時に判定します。

【CPU】
CPUはプレイヤーの行動を見ずに選択します。HPが少なくなると
頭と腰の防御を選ぶ確率が少し高くなります。

【オンライン部屋】
「オンライン部屋」から6桁の部屋番号を作成できます。
部屋番号のコピーと、番号入力による参加準備に対応しています。
部屋を作った側はハク、番号を入力して参加した側はゆやです。
役割と「部屋作成完了／参加準備完了」を画面に表示します。
Firebase匿名ログインとFirestoreを使い、2台のブラウザ間で部屋参加、
行動、HP、ラウンド、勝敗をリアルタイム同期します。

【2PC通信テスト】
1. GitHub Pagesへ全ファイルをアップロードします。
2. PC1でオンライン部屋を作成します（ハク）。
3. PC2で同じページを開き、6桁の番号で参加します（ゆや）。
4. 両画面に「2台の接続完了」が表示されたら行動を選びます。
5. 攻撃、HP、ラウンド、勝敗は両画面で同期されます。

firebase-network.js：Firebase接続とリアルタイム同期
firestore.rules：Firebase Consoleへ公開した安全ルールの控え

【ルール】
開始HP：100
頭攻撃：25ダメージ／腰攻撃：20／足攻撃：15
同じ場所を攻撃：引き分け、ダメージなし
頭＋腰防御：頭・腰への攻撃はダメージ0、攻撃側に10ダメージ
足防御：足への攻撃はダメージ0、攻撃側に10ダメージ
防御箇所と異なる場所への攻撃は通常どおりダメージ
HPが0になると水に落ち、勝敗判定

【試し方】
ZIPを展開し、index.htmlをブラウザで開いてください。

【画像構成：全15枚】
プール背景：黄色と紫の足場付き1枚
ハク：待機、頭攻撃、腰攻撃、足攻撃、上半身防御、足防御、水落の7枚
ゆや：待機、頭攻撃、腰攻撃、足攻撃、上半身防御、足防御、水落の7枚

両者が行動を選ぶと対応する攻撃・防御画像へ切り替わり、
約1秒後に待機画像へ戻ります。HP 0では水落画像へ切り替わります。
攻撃画像は相手方向へ前進し、防御画像は構え、HP 0画像は水面方向へ
下降します。攻撃時には画面中央へ衝突エフェクトが表示されます。
状態、判定、描画、オンライン拡張口はgame.js内で分離しています。
今後、画像、演出、CPU戦、オンライン通信を段階的に追加できます。
